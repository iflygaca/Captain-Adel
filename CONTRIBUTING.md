# Contributing

Captain Adel is proprietary, source-visible software — see [LICENSE](LICENSE). We don't accept
code contributions, but bug reports and regulation-accuracy corrections are very welcome via
[issues](https://github.com/ay2m/Captain-Adel/issues).

Every behavioural change to the brain is eval-gated — see [evals/README.md](evals/README.md)
before proposing one. Found a security issue? See [SECURITY.md](SECURITY.md) instead of
opening a public issue.
