# Security policy

Captain Adel (captadel.com) is a live service that handles authentication and payments. If you
find a vulnerability, email **hello@captadel.com** with steps to reproduce. We aim to
acknowledge reports within 72 hours.

Please don't test against production user data, attempt to access other users' accounts or
payment information, or run automated scanners against the live site or API. There's no bounty
program today, but we credit reporters who disclose responsibly.

## Scope

- captadel.com — the site, chat, and `/v1/*` API
- This repository's source code

Out of scope: social engineering, physical security, and third-party services we depend on
(Firebase, Moyasar, Google Gemini, Cloudflare) — please report those directly to their owners.
